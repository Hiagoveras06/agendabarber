# Agenda Barber

Este projeto é uma página estática. Por enquanto, não usa React, Supabase ou
banco de dados.

## Executar localmente

```bash
npm install
npm run dev
```

Abra o endereço exibido no terminal (normalmente `http://localhost:5173`).

## Publicar no Vercel

Use a raiz do repositório como **Root Directory**, deixe o framework como
**Vite**, use `npm run build` como comando de build e `dist` como diretório de
saída. O projeto não precisa de configuração ou credenciais de banco de dados.
